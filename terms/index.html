서비스 이용 조건

SmartDK Backup은 승인된 내부 운영자가 재해 복구를 위해 사용하는 전용 백업 도구입니다.

시행일: 2026년 10월 10일

1. 서비스 범위

이 도구는 SmartDK의 DB·첨부 및 복구 관련 자료를 관리자 지정 Google Drive 저장소에 보관하고 필요시 복원하도록 지원합니다. 일반 사용자에게 계정·파일 공유 서비스로 제공되지 않습니다.

2. 관리자 책임

승인된 관리자는 Google 계정의 적법한 사용, 백업 대상과 접근 권한 설정, 저장 용량, 독립적인 복구키 보관, 주기적인 복원 시험을 관리해야 합니다.

3. 백업 상태와 복구

백업 객체의 전송 성공만으로 DB와 모든 첨부가 특정 시점에 완전 복원된다는 보장이 성립하지 않습니다. 운영자는 백업·검증 결과를 확인하고 실제 복구 절차를 시험해야 합니다. 목표 복구 시간은 별도의 운영 인수 및 테스트 결과로 판단합니다.

4. Google 서비스

Google Drive API 접근은 관리자의 OAuth 동의와 Google의 약관·사용 정책에 따릅니다. 연결을 철회하거나 Drive에서 백업을 삭제하면 후속 백업이나 복원이 제한될 수 있습니다.
