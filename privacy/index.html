개인정보처리방침

SmartDK Backup은 승인된 관리자에 의한 재해 복구 백업을 위해 Google Drive에 접근합니다.

시행일: 2026년 10월 10일

1. 처리 목적

SmartDK 업무 시스템의 복구 가능한 백업 파일을 생성·보관·검증·다운로드하기 위해 Google Drive API를 사용합니다. Google 계정 데이터는 광고, 사용자 프로파일링 또는 다른 목적에 사용하지 않습니다.

2. 접근하는 정보와 권한

백업 도구는 관리자의 Google OAuth 동의를 통해 접근 권한을 받습니다. drive.file 권한으로 애플리케이션이 만들었거나 사용자가 접근을 허용한 Drive 파일을 처리하도록 구성합니다. 승인된 계정의 OAuth 토큰, 백업 객체 및 전송 결과 정보가 운영에 필요할 수 있습니다.

3. 업무 데이터의 백업

백업에는 SmartDK 데이터베이스와 문서 첨부 등 개인정보 또는 기밀정보가 포함될 수 있습니다. 외부 전송은 암호화된 백업 저장소를 이용하도록 설계하였으며, 운영자가 실제 연결을 활성화한 경우에만 데이터를 전송합니다. 이 공개 웹사이트 자체는 업무 데이터의 업로드 기능을 제공하지 않습니다.

4. 보관·보호·접근

백업 데이터는 관리자가 선택한 Google Drive 계정과 저장소에 보관됩니다. OAuth 인증정보는 접근이 제한된 운영 설정에서 관리합니다. 백업 암호 및 애플리케이션 복구키는 Google Drive와 독립적으로 관리해야 합니다. 보존기간과 삭제는 실제 적용된 관리자의 백업 정책에 따르며, 자동 삭제 정책이 설정되지 않은 경우 관리자에 의해 수동으로 관리됩니다.

5. 제3자 제공과 처리 위탁

백업 데이터를 광고 또는 마케팅 목적으로 판매하거나 제공하지 않습니다. Google Drive는 관리자가 지정한 백업 저장 위치이며, GitHub Pages는 본 안내 웹사이트의 호스팅 제공자입니다. 각 서비스에는 해당 제공자의 서비스 약관 및 개인정보 정책이 적용됩니다.

6. 동의 철회와 데이터 삭제

관리자는 Google 계정의 보안·제3자 앱 액세스 설정에서 SmartDK Backup의 OAuth 연결을 철회할 수 있습니다. 철회는 향후 API 접근을 중단하지만 기존 백업 파일을 자동으로 삭제하지는 않습니다. 기존 파일과 저장소의 삭제는 해당 Google Drive 계정의 관리자가 수행합니다.

7. 공개 사이트 기록

이 안내 사이트에는 별도의 분석 도구, 광고 스크립트 또는 추적 쿠키를 설치하지 않습니다. 사이트를 제공하는 GitHub Pages에서 기술적인 접속 기록을 처리할 수 있습니다.
